# 보글보글 떡볶이

작은 골목 분식집에서 주문을 받고, 재료를 원하는 만큼 담아 직접 끓이는 PC·모바일 브라우저 게임입니다.

[바로 플레이 — PC·모바일](https://hadangs516.github.io/bogeul-tteokbokki/) · [GitHub 소스](https://github.com/hadangs516/bogeul-tteokbokki)

## 실행

- PC와 휴대폰 모두 위의 **바로 플레이** 링크로 접속하면 됩니다.
- GitHub에서 소스를 받은 경우 Node.js 24 환경에서 저장소 폴더를 열고 `npm start`를 실행한 뒤 [로컬 게임 열기](http://localhost:4173)로 접속합니다.
- `실행하기.cmd`가 포함된 로컬 배포본은 해당 파일을 더블클릭해 실행할 수 있습니다. 이 실행 파일은 GitHub 저장소에 포함되지 않습니다.
- 패키지 설치, 계정, API 키는 필요하지 않습니다. 로컬 서버를 종료하려면 실행 창을 닫습니다.
- 로컬 실행 서버는 이 PC에서만 접속할 수 있습니다. 휴대폰에서는 위의 공개 플레이 링크를 이용합니다.

## 한 그릇 만들기

1. 손님 말을 듣고 **주문 받고 주방으로** 이동합니다.
2. 재료를 누를 때마다 1단위씩 담깁니다. **−**로 덜어낼 수 있고, 주문 메모에서 목표량과 현재량을 봅니다.
3. 소스와 맵기를 고르고 불을 켭니다.
4. 중불에서 5~8초마다 한 번씩 젓습니다. **젓기 버튼**이나 냄비를 문지르는 동작을 쓸 수 있습니다. 잘 관리하면 끓이는 과정은 약 39~40초이며, 조리 시간 55초에는 자동으로 끝납니다.
5. 충분히 익으면 불을 끄고 그릇을 고른 뒤 손님에게 가져갑니다. 준비·담기 속도에 따라 전체 한 그릇은 약 1분을 목표로 합니다.

손님마다 좋아하는 양·맵기·빼는 재료가 다릅니다. 한 재료는 12단위, 냄비 전체는 60단위까지 담을 수 있습니다. 팁과 경험치를 모아 가게를 키우고, 영업일에 따라 총 8종의 레시피를 엽니다.

설정에서 효과음·음악·느긋한 모드를 바꿀 수 있습니다. 설정과 정보 창을 열거나 브라우저 탭이 숨겨지면 조리가 멈춥니다. 진행은 **같은 브라우저·같은 주소**에 자동 저장되며 다른 기기와 동기화되지 않습니다.
